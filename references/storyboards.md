# 分镜、时间与制作记录

来源：S108–S141、S146–S147、S152。原表格有空白样表、拍摄日志、拉片表和组合词库，它们承担不同任务。

## 从故事到镜头

先确定整片目标时长与画幅，再列信息节拍：每一节回答“观众此刻多知道了什么、角色或物体发生了什么变化”。一个镜头容纳一个主要任务。先估计动作所需时间，再选镜头数；九宫格是画面排版方式，不自动等于九个固定时长的视频片段。

多镜头标准字段：

| 字段 | 要记录的内容 |
| --- | --- |
| 镜号、起止、时长 | 连续编号，统一用秒；成片时间与拍摄耗时分开 |
| 主体、场景、初始状态 | 人物/产品 ID，位置、朝向、道具状态 |
| 画面与动作 | 可观察的动作过程和结束状态 |
| 景别与机位 | 全/中/近/特写，角度与观察方向 |
| 运镜 | 起幅→路径/速度→落幅；固定镜头也写清 |
| 对白、旁白、字幕 | 分开记录；字幕可与旁白不同，但不得改变意思 |
| 音乐与音效 | 各自的进入点、延续、退出或同步动作 |
| 转场与连续性 | 硬切、动作连接、遮挡或叠化；连接的具体元素 |
| 素材与制作 | 参考图、素材 ID、服装、道具、地点、必要备注 |

只需一个提示词时不展开全部字段。拍摄计划另外记录拍摄日期、人员、设备、场次、条次、进度和问题；不要把这类工时算作成片时长。

## 时间检查

将时间轴作为最终成片的基准。第一镜从 0 开始；前镜结束等于后镜开始；最后结束等于目标时长。所有时间均为正向有效区间。需叠化时，明确叠化占用时间及成片剪辑位置，额外生成的首尾余量列为“素材余量”，不额外计入成片。

对白应能在分配时段说完；同步复杂动作先拆步骤。脚本检查器能发现数字错误和缺失角色引用，不能判断真实表演能否完成；仍需试读、预演或实际生成检验。

## 静态图和视频分开写

- 静态图：角色特征、场景、画幅内位置、当前姿态、景别、光线、材质。
- 图生视频：继承参考图哪些特征，主体与环境如何变化，摄像机如何移动，最后停在哪里。
- 多镜头生成：每镜各有一段可独立复制的正文。跨镜头仍重复关键身份特征；不能只写“人物同上”。

若工具支持多镜头时间指令，再按其当前能力合并；不因原资料用了“切镜”就假定所有模型支持。画面中的精确文字、Logo、字幕与复杂排版，优先保留后期制作位置，并根据工具实测决定生成方式。

## 连续性检查

逐镜检查人物位置和运动方向、手上道具、服饰发型、产品结构、光源方向、时间天气，以及动作开始和结束状态。需要反向视角时交代新的机位；想打破方向连续性时应有清楚的叙事目的。

转场要有实际连接点，例如圆形杯口切圆形车轮、同一只手抬起到下一镜落下、门框遮挡后换空间。不要只写“高级丝滑转场”。
