# 漫剧角色、世界与美术

主要来源：S015、S025–S027、S032–S034、S041–S042、S076、S092–S098、S141–S145、S149。

## 角色卡的六个层次

1. 身份和叙事作用：成年/儿童、职业或物种、故事目标，与其他角色的关系。
2. 固定外形：脸型、发型、眼睛等少量可辨识特征；动物则是体形、毛色和标记。
3. 服装道具：颜色、材质、轮廓、佩戴位置及关键物件。
4. 表情与身体状态：本镜的可变情绪和姿态，不覆盖固定外形。
5. 世界与视觉：年代、环境规则、画风、材质、主色和光源。
6. 本镜动作：从何状态开始、动作如何发生、最终状态。

将 1–3 作为跨镜头重复的身份锚点，4 和 6 按剧情变化，5 保持世界统一。不要堆太多微小特征导致主要辨识点淹没。已有参考图时优先描述需要保留的可见特征，不凭空推断人物背景。

定妆可做正面、侧面、背面、表情和关键道具图；视图数量按需要决定。提示词不能保证角色锁定，最终要核对实际生成结果。若用参考图、角色 ID 或其他一致性功能，先确认当前工具支持。

## 小说改编为可见的故事

提取目标、冲突、行动、结果和世界规则。内心独白可转成行为细节、反应镜头、道具或短旁白；不要把一大段心理说明塞进图像提示词。对话每次推进关系或信息，配合停顿和反应留出时间。

科幻和奇幻先声明几条稳定规则，随后让冲突发生在规则中。悬疑故事单列事件时间线、角色所知、线索出现点和揭示点，防止角色提前知道秘密。影视分析、二次创作与原创故事应在交付时说明各自性质。

## 变身与拟人

S015 的物品拟人、S041 的神兽、S042 的机甲都可提炼为“共同视觉母题 + 阶段状态”。例如同一条青色裂纹贯穿石像、半觉醒形态和完整生物，轮廓或道具也有对应关系。每阶段先做清楚的静态状态，再设计相邻状态的局部变化。

人形→半人形→兽形等六阶段只是来源案例，不是必须步骤。不要把六张不同形态描述误当成已验证的连续变身视频。复杂变身可分成多个短段，让起止状态可检查。

群像明确数量、前后层次、各自服装与主次关系。人和巨大动物明确相对尺度及同一地面的接触关系。儿童绘本和萌宠日常用稳定外观加简单生活动作，重复地点和道具帮助理解。

## 美术设计卡

| 项目 | 需要决定的问题 |
| --- | --- |
| 世界与空间 | 年代、地域、生活方式、空间尺度、主要路径 |
| 色彩与材质 | 主色、辅色、强调色；木、金属、布、皮肤等的可见质感 |
| 光线 | 光从哪里来、软硬、明暗范围、时间和天气 |
| 服装与道具 | 与人物身份、行动及世界规则是否一致 |
| 构图 | 主要信息在哪里，前中后景怎样组织 |
| 情绪变化 | 场景如何通过空间、光、动作变化表达情绪 |

颜色与情绪的关系取决于情境，不固定“蓝色必然悲伤”。参考风格词库中出现的导演、作品和平台名称时，优先改写成可见的色彩、景别、构图、节奏与材质特征。

## 修正来源中的固定假设

S142 把 4:3 称为竖屏，应按宽高比解释：4:3 横向，3:4 纵向。S144 的示例 LoRA 字符串不代表本地存在相应模型。S094、S097、S098 的特定服饰和身体描述只属于原案例，不作为角色创作默认值；服装由当前人物、场景和用户要求决定。
