# 镜头语言与组合运镜

来源：S001–S008、S136、S139、S143、S145。以下将源资料中混写的术语拆开，示例重新编写。

## 六个独立维度

| 维度 | 回答的问题 | 示例 |
| --- | --- | --- |
| 景别 | 主体占多少画面 | 环境远景、人物全身、中景、手部特写 |
| 角度 | 从哪里看 | 平视、俯视、仰视、过肩、第一人称 |
| 机位运动 | 摄像机怎样移动 | 推进、后退、侧移、升降、环绕 |
| 镜头朝向 | 摄像机原地朝哪里转 | 水平摇摄、上下俯仰、绕光轴旋转 |
| 焦距与焦点 | 视野和清晰区域怎样变化 | 广角、长焦、变焦、焦点转移 |
| 时间与剪辑 | 如何组织多个画面 | 慢动作、延时、切镜、叠化、分屏 |

“特写+仰角+缓推+浅景深”可以组合；特写本身不是运镜。长镜头指连续拍摄时长，不等于长焦。固定机位允许人物运动或焦点转移。

## 按叙事目的选择

| 目的 | 表达方式 | 需要写清 |
| --- | --- | --- |
| 靠近情绪或细节 | 中景缓推至手部特写 | 起点、终点、时长、焦点 |
| 揭示环境或孤独 | 面部近景后退到人物全景 | 新揭示什么环境 |
| 陪伴行动 | 在人物右侧平行跟随 | 人物方向、相对距离、画面位置 |
| 搜索线索 | 固定机位从左向右摇摄 | 先看到什么、发现什么、停在哪 |
| 展示空间高度 | 摄像机从腰高抬升 | 机位升高或原地抬头，不能含混 |
| 展示立体关系 | 沿主体右侧弧线移动约 60° | 绕行方向、角度、主体是否转动 |
| 纪实与紧张 | 轻微手持起伏跟随 | 抖动幅度，不能同时要求完全无抖动 |
| 线索接反应 | 焦点从前景钥匙转向后景人物 | 相对位置、变化时间、机位是否固定 |
| 心理空间变形 | 推轨配合反向变焦，主体大小近似不变 | 实际工具支持及背景预期变化 |
| 等待情绪发生 | 固定机位等一个动作发生 | 给主体动作和停顿留时间 |

情绪与运镜是创作选择，不是固定因果规律。上升也可揭示危险，暖光也可表达压迫，以当前叙事为准。

## 组合镜头

每段都有触发点和落幅。多个地点、大角度绕行、变身和激烈交互同时发生时优先拆镜。

```text
0–2 秒：桌面钥匙特写，人物手伸入画面并拿起钥匙；机位固定。
2–4 秒：随抬起的手缓慢上摇至人物头肩中近景，钥匙停在胸前，面部也进入画面。
4–6 秒：停止摇摄，焦点转向人物面部；人物看向门口，保持一秒。
```

若跨度过大造成变形，拆为“拿起钥匙特写”和“人物反应近景”，以动作匹配连接。不要同时要求“全程一镜到底”和“切到另一机位”。

## 静态与动态配对

**首帧**：清晨窗边，一位穿灰蓝围裙的成年陶艺师双手托住未上釉的陶杯，杯身完整，桌面只有一块湿布。中景平视，柔和侧光从画面左侧照入，杯口和双手清晰。

**视频**：保持陶艺师、围裙、陶杯形状及桌面布局一致。她用双手将杯子轻转约四分之一圈后停稳。摄影机在 5 秒内缓慢推进到杯身近景，侧光沿杯壁移动，背景逐渐虚化。杯口不变形，双手始终各握杯身一侧，不新增道具。

静态图写一个姿态；视频写状态变化。主体运动与摄像机运动分别交代。

## 原文术语修正

- S007 把“推远”写入推镜说明；以空间距离实际变化命名。
- S008 把“移”解释为上下展示；区分机位位移与原地俯仰。
- S143/S145 部分“环形摇镜”实际为环绕；反复变焦也不等于焦点转移。
- S145 的“2 秒/帧”慢推速度改为总时长与起止构图。
- S001/S006 的穿玻璃、进入照片是创意转场，不是每个工具稳定支持的功能。
